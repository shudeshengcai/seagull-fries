## 自我介绍

大家好，我是生菜，上一世我是一个白天写代码、下班被海鸥叼走薯条的人。这一世我重生了，我的身份是「叼走薯条的海鸥」
——代码一行没写，意见提了一箩筐。

## 我的作品是什么

**任何人打开浏览器，就能扮演一只海鸥，在种子随机生成的港口里按顺序叼薯条、攒钱买装扮的 3D 飞行小游戏。** 手机、电脑都能玩，整个游戏只有一个 390KB 的 HTML 文件，零外部资源、断网也能飞。
贴图全部是柏林噪声和位移偏移生成的锈迹，声音来自于合成音频

## 为什么做

「去码头整点薯条」是全网海鸥的表情包共识，但没人真让你当过那只海鸥。我想把这句梗变成一个能上手的东西：顺便验证一件事——不装引擎、不找素材、不联网，纯靠 Qoder 手写 WebGL2 和合成音频，能不能做出一个有物理、有天气、有商店、手机也能玩的完整游戏。答案是可以，而且过程相当欢乐。

## 怎么用（5 步）

1. 点开上面的链接，等加载完（包含文件载入与性能测评，自动选择画质，大约5-7秒）。
2. 选地图和海鸥：晴空码头练手 → 集装箱峡谷穿梭 → 暴雨工业港挑战（第三关只允许健硕/轻盈海鸥，雷暴自带闪电照明）。
3. 点起飞。电脑 WASD/方向键 + Q/E 转向，手机用屏幕按键；跟着引导线，**严格按顺序**叼薯条。
4. 薯条进钱包，去商店买饰品；输入作弊码 `V我50` 直接财务自由。
5. 第三关巨无霸薯条一根顶 100 根，但坠机一次本局收益全清——坠机时屏幕会送你一句「Man! What Can I Say!」。祝好运。

## 用 Qoder 做出来的过程

分工很明确：**Qoder 负责全部工程，我负责玩、截图、挑刺。** 前后迭代了约 30 轮：

- **第 1 阶段｜从零到能飞**：我把一份工程规格书丢给 Qoder，它手写了 WebGL2 渲染器、240Hz 定步长物理、PID 控制律、碰撞与炸机状态机、程序化港口和合成音效。我试玩后反馈「WASD 没反应」「看不到建模」，它重做了操控方案并加了小白跟随模式。
